# PsyDefDetect Local Literature Catalog

This local catalog is the only literature context projected into the
PsyDefDetect evaluation. The task concerns psychological defense mechanism
classification from supportive dialogue, a fixed dialogue-level split, and
macro-F1 over positive labels 1-8. The catalog is intentionally concise and
does not prescribe an algorithm or representation.

The framework should use this context to form its own hypothesis, explain
failure modes, and choose two materially different experiments from the
installed resources.
